# PH Get Started prototype

Proposal UI for the Whoscall Android onboarding first screen (PH market test).

- **V1 · Simulated call (story)**: the phone rings, the Whoscall call dialog slides in and shows "Scammer", Decline is tapped and the call is blocked.
- **V2 · Before / After (slider)**: drag the slider toward After and the background glows.

Each version has C1 (caller ID) and C2 (Phone + Viber + WhatsApp) copy. Phone screens are 2x exports from Figma.

Live page: https://vernagong-lab.github.io/ph-getstarted-prototype/
